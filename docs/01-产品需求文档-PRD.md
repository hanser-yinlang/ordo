## 1. 产品定位

Ordo 面向"用一张清单管理整个人生"的个人用户:把散落的任务收进收件箱,按"何时开始"分流到 今天 / 今晚 / 计划 / 随时 / 某天,用项目与标题拆解大目标,用标签跨清单切片,完成后进入日志簿留痕。

**价值主张**:结构清晰、录入极快(中文自然语言)、四端一致、离线可用、多设备同步。

## 2. 目标用户与场景

| 画像 | 特征 | 关键诉求 |
|---|---|---|
| 知识工作者(主) | 项目多、会议多、任务杂 | 今天清单要能一眼看清;快速录入不打断心流 |
| 学生 | 周期任务(作业/复习)、长期目标 | 重复任务、计划视图、低成本回顾 |
| 自由职业者 | 客户/项目并行 | 区域-项目结构、标签切片、订阅账单类重复待办 |
| 家庭管理者 | 采购清单、家务 | 清单(Checklist)、提醒、共享前夜的"购物模式" |

**不服务**:需要多人协作/权限管理的团队(本期明确不做)。

## 4. 核心用户旅程(每端验收脚本)

1. **晨间规划**:打开 → 今天 → 把 3 条待办从"随时"拖进今天 → 给其中一条设 18:00 提醒。
2. **快速捕捉**:任意界面唤出快加号 → 输入「下周三 15:00 与设计师评审 #重要」→ 回车 → 断言落入计划视图并带标签与提醒。
3. **项目推进**:进入 Q4 产品发布 → 展开发开标题 → 勾选两条子项 → 进度环变化 → 归档标题(需先完成全部子项)。
4. **清单购物**:打开"补充家庭药箱" → 勾选 2 项 → 进度显示 2/3 → 完成整条待办 → 日志簿出现记录。
5. **重复任务**:完成"每周复盘"(每周重复)→ 自动生成下周同一日的新实例,清单项重置。
6. **回顾**:进入日志簿 → 按日分组查看昨天完成项 → 恢复其中一条 → 回到原清单。
7. **多设备一致**(需后端):A 端新建 → B 端 3 秒内出现;B 端打勾 → A 端该条消失并进日志簿。
8. **离线可用**:断网 → 新建/完成多条 → 恢复网络 → 自动同步成功且无重复条目。

## 5. 非功能需求

| 类别 | 指标 |
|---|---|
| 性能 | 冷启动 ≤ 2s;3000 条待办下滚动 60fps;本地查询 ≤ 50ms |
| 容量 | 单账号 ≤ 50,000 实体;单次 push ≤ 500 ops(契约 §7.4) |
| 可用性 | 同步失败不阻塞界面;错误可重试且不丢数据 |
| 安全 | 口令 argon2id;令牌轮换;日志不打印敏感数据(契约 §9) |
| 隐私 | 不上传日历/通讯录;提供账号与数据删除 |
| 兼容 | Android 8+(minSdk 26)、iOS 16+、鸿蒙 API 12+、Windows 10 1809+ |
| 本地化 | 简体中文(默认),预留英文文案资源结构 |
