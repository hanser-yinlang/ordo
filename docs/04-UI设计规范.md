## 2. 设计令牌(Design Tokens)

> 四端实现为各自的主题常量;命名一致,值一致。浅色 / 深色必须同时实现。

| Token | 浅色 | 深色 | 用途 |

| `bg.sidebar` | `#F4F3EF` | `#191919` | 侧栏 |
| `line.hairline` | `#E7E5DF` | `#2E2E33` | 分隔线 |
| `text.primary` | `#1C1B19` | `#F2F1EE` | 主文字 |
| `text.secondary` | `#7A776F` | `#9A968E` | 次要信息 |
| `text.tertiary` | `#A8A49B` | `#6E6B65` | 占位、禁用 |
| `accent.primary` | `#5B5BD6` | `#7C7CF0` | 主强调(选中、复选框、主按钮) |

|---|---|---|---|
| `font.display` | 28 / 34 | 600 | 清单大标题 |

```
┌──────────────┬───────────────────────────────────────────────┐
│ 侧栏 248px    │ 大标题 28/34 + 计数 + 工具按钮                  │
│ (可折叠)      ├───────────────────────────────────────────────┤
│ · 收件箱       │ 内容区(最大宽度 720,居中)                     │
│ · 今天         │  ├ 日程区块(只读日历事件)                      │
│ · 计划         │  ├ 分组标题 / 标题(Heading)                    │
│ · 随时         │  ├ 待办行(高 38,圆角 10)                      │
│ · 某天         │  └ 今晚分区(琥珀色分组标题)                    │
│ · 日志簿       │                                               │
│ ─ 区域         │                                               │
│   └ 项目(进度环)│                                               │
│ ─ 标签         │                                    [快加号 ◉] │
├──────────────┴───────────────────────────────────────────────┤
│ 状态栏:共 N 项 · 已完成 M 项 · 同步状态(已同步/同步中/离线)      │
└──────────────────────────────────────────────────────────────┘
```

| 断点 | 行为 |
|---|---|
| ≥ 1100px | 三栏(侧栏常驻)+ 详情以内联卡片展开 |
| 768–1099px | 侧栏可收起为图标条;iPad 竖屏侧栏抽屉化 |
| < 768px | 侧栏变抽屉(汉堡 + 遮罩);详情变为全屏 sheet |
| Windows 桌面 | 支持多窗口,每窗口独立路由;窗口最小 480×640 |

## 4. 组件规范

| 组件 | 规格 |
|---|---|
| 侧栏项 | 高 34,左内边距 12,图标 18,文字 15/22;选中态 = `accent.primary` 12% 底 + 图标着主色;右侧计数 13/18 `text.secondary` |

| 待办行 | 高 38;左侧复选框 20×20 圆形,未完成 1.6px `#C6C3BA` 描边;标题 15/22;元信息行 13/18(gap 6) |
| 复选框 | 完成:填充 `accent.primary` + 白色对勾;取消:canceled 用 `state.danger` 描边 + 斜线 |
| 标签 chip | 高 20,内边距 6/2,圆角 pill,`chip.bg`;可点击进入标签视图 |
| 元信息 pill | 图标 14 + 文字 13;提醒用铃铛;逾期/过期用 `state.danger`;清单进度 `2/5` |
| 详情卡片 | 白纸感:圆角 14,内边距 16,标题输入 20/26,备注 Markdown 预览,字段区为可点胶囊按钮(`何时 / 截止 / 提醒 / 重复 / 移动到 / 标签 / 清单`) |

## 5. 关键动效(统一时序,四端一致)

**完成一条待办**(从触摸/点击到从列表消失)

| 时间 | 动作 |
|---|---|
| 0ms | 按压反馈:复选框 scale → 0.92(90ms) |
| 80ms | 圆圈填充 `accent.primary`(scale 0.92 → 1.06 → 1,spring) |
| 160ms | 白色对勾 stroke-dashoffset 0 → 1(120ms) |
| 240ms | 标题转 `text.tertiary` + 删除线;行透明度 → 0.72 |
| 700ms | 行高度收起 + 透明度 → 0(180ms ease-in)后从列表移除;侧栏计数与项目进度环同步(220ms ease-out) |
| 900ms | 项目完成度到达 100% 时,进度环播放一次高亮脉冲 |

其他:清单展开 220ms ease-out;侧栏折叠 260ms;浮层 pop-in 180ms `scale(.98)→1`;页面切换淡入 160ms。
**必须遵守系统的"减弱动态效果"设置**:开启后所有动效降为 0ms 直接切换。

## 8. 无障碍(A11y)基线

- 触控目标 ≥ 44×44(移动)/ 32×32(桌面)。
- 所有交互元素提供可读标签(TalkBack / VoiceOver / 屏幕朗读 / Narrator)。
- 支持系统字体缩放至 200% 不截断(布局允许换行与增高)。
- 不仅靠颜色传达状态:逾期同时有图标与文案,完成同时有勾选图形。
- 深浅色、放大字号、减弱动效三种系统设置必须被遵循。
