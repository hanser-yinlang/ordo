## 2. 用例设计(核心规则,必须逐条覆盖)

### 2.1 日期引擎(L1)

| 用例 | 期望 |
|---|---|
| 闰年判断 | 2024/2028 为闰年;2100 非闰年 |
| 月末溢出 | `2026-01-31 + 1 月 = 2026-02-28`;`2028-01-31 + 1 月 = 2028-02-29` |
| 跨年 | `2026-12-31 + 1 天 = 2027-01-01` |
| 星期 | `2026-10-08` = 周四;`2026-10-10` = 周六 |
| 日期差 | `daysBetween("2026-10-01","2026-10-08") = 7` |

### 2.2 中文 NLP(契约 §5,全部写法)

明天 / 后天 / 大后天 / N 天后 / N 周后 / N 个月后 / 今天 / 今晚 / 某天 / 周末 / 周X / 下周X / 下下周三 / M月D日 / M-D / YYYY-MM-DD / `HH:mm` / `H点` / `H点半` / `上午H点` / `下午H点` / `晚上H点` / `Hpm` / `#标签` / 组合输入。
**每条断言三件事**:`cleanTitle` 干净、`when/date` 正确、`reminder` 正确(如有时间)。

### 2.3 派生清单(契约 §4)

收件箱只含 `when=inbox`;今天包含"今天开始 + 今天及以前到期 + 已逾期截止";今晚与今天互斥分组;计划窗口 14 天且超出归「更晚」;随时/某天不相交;日志簿按完成日倒序;项目按标题分组;标签视图默认排除已完成;搜索命中标题与备注;计数与列表长度一致。

### 2.4 重复(契约 §6)

daily/weekly/monthly/yearly × fixed/afterCompletion;月末溢出;完成后生成新实例且清单项重置;非重复待办不生成。

### 2.5 同步与冲突(契约 §7)

| 用例 | 期望 |
|---|---|
| 幂等 | 同一 `opId` 推送两次仅生效一次 |
| LWW | `clientTs` 大者胜;过期 op 被丢弃 |
| 完成不可回滚 | 本地已 done,远端旧 open 不生效;显式 reopen 生效 |
| 标签并集 | 两端标签合并保留 |
| 清单项合并 | 两端独有项都保留 |
| 墓碑 | 删除后旧 upsert 不能复活 |
| 捎带拉取 | push 响应中的 ops 被应用 |
| 分页 | pull 按 limit 分页,`hasMore` 正确 |
| 401 | 刷新令牌后重放一次成功 |

### 2.6 后端接口(L1)

注册/重复邮箱/登录失败/刷新轮换/受保护路由 401;限流(>10 req/s → `RATE_LIMITED`);单次 >500 ops 或 payload >256KB → `SYNC_OP_TOO_LARGE`;提醒到点仅投递一次。

## 4. 性能与稳定性测试

| 项 | 方法 | 门槛 |
|---|---|---|
| 大列表 | 生成 3000 条待办,滚动今天/计划 | 无掉帧;查询 ≤ 50ms |
| 冷启动 | 三次取平均 | ≤ 2s |
| 同步压力 | 500 ops 批量推送 × 20 轮 | 无丢失、无重复 |
| 长连接 | WS 保持 30 分钟并断线重连 | 自动恢复且不丢 ops |
| 弱网 | 限速 200kbps + 10% 丢包 | 不崩溃,outbox 最终一致 |
