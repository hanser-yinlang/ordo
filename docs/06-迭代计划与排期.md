## 2. 迭代明细

| 工作项 | 产出 | 负责人 |
|---|---|---|

| 数据模型/同步协议冻结 | `docs/03` | 架构师 |

| 工具链准备 | JDK 21 + Gradle 8.14 就绪 | 架构师 |

**出口标准**:契约评审通过;四端可并行开工。✅

### Sprint 1(第 2 周)· 共享核心与后端 — ✅ 已完成

| 工作项 | 产出 | 负责人 |
|---|---|---|
| KMP 共享核心(模型/查询/NLP/重复/同步/存储抽象) | `shared/core`(26 个源文件) | 架构师 |
| 核心单元测试 | 4 个测试类,≥40 用例 | 架构师 |
| 后端(认证/同步/WS/Fastlane/限流) | `server/src` | 后端 |

| 四端 MVP 源码 | `apps/*` | 各端 |

**出口标准**:`gradle :shared:core:jvmTest` 与 `pnpm test` 全绿。✅(见 §4 实测记录)

### Sprint 2(第 3–4 周)· 四端骨架与本地闭环

| 目标 | 四端各自跑通:收件箱 → 今天 → 项目 → 标签 → 日志簿,新建/完成/详情可用(纯本地) |
|---|---|
| Android | 接入 `shared/core`(JVM/Android 目标),SQLite 存储落地,Compose 三栏骨架 | 
| iOS | 生成 `OrdoCore.xcframework`,SwiftData 存储,SwiftUI 骨架 |
| 鸿蒙 | ArkTS 核心 + RelationalStore + ArkUI 骨架 |
| Windows | Compose Desktop 骨架 + 文件仓储;真实构建通过 |
| 共同出口 | 每端"今天"清单可见演示数据并能完成一条待办 |

**风险**:iOS 桥接首次打通成本高(预留 2 天缓冲)。

### Sprint 3(第 5–6 周)· 账户与同步联调

| 目标 | 四端接入 `SyncApi` + WebSocket;多设备一致性用例通过 |
|---|---|
| 工作项 | 登录/注册界面 · 令牌刷新 · outbox 重试 · 冲突用例(E2E) · 全量重建 |
| 出口 | M4:两端并发写测试通过;同步失败不丢数据 |
| 依赖 | 需要一台可访问的后端实例(本地 Docker 或云主机) |

### Sprint 4(第 7–8 周)· 系统能力与体验

| 目标 | 提醒通知、深链、深色模式、键盘快捷键、无障碍达标 |
|---|---|
| 工作项 | WorkManager / UNNotification / reminderAgent / 托盘通知 · `ordo://` 四端注册 · Fastlane 端到端验证 · 读屏走查 |
| 出口 | M3 + 提醒链路端到端可用(服务端到点 → 设备通知 → 点击进入待办) |

### Sprint 5(第 9–10 周)· 打磨与性能

| 目标 | 性能门槛达标(冷启动 ≤2s / 3000 条不掉帧)、批量操作、导出、错误态与空态完善 |
|---|---|
| 工作项 | 列表虚拟化与增量重组 · 批量多选 · 数据导出(JSON/Markdown) · 崩溃与日志上报 · 文案统一 |
| 出口 | 性能测试报告通过 |

### Sprint 6(第 11–12 周)· 上架与验收

| 目标 | M5 发布候选 |
|---|---|
| 工作项 | 各商店材料(隐私清单/数据安全表/隐私声明/签名) · 灰度发布方案 · 用户手册 · 验收演示 |
| 出口 | 客户验收签字;移交清单全部勾选 |

## 5. 依赖与假设

| 项 | 说明 |
