## 2. 知识产权与合规

### 2.1 与参考产品的边界(硬性)

| 允许 | 禁止 |

## 3. 安全设计

### 3.1 威胁模型(STRIDE 摘要)

| 威胁 | 场景 | 对策 |
|---|---|---|
| Spoofing | 伪造令牌访问他人数据 | JWT 签名 + refresh 轮换 + 每请求校验 user 归属 |
| Tampering | 篡改同步 payload 注入越权实体 | 服务端校验 entity/entityId 归属;payload 结构与长度校验 |
| Repudiation | 否认操作 | `ops` 表保留 opId/deviceId/时间戳审计 |
| Information disclosure | 日志/错误泄露敏感信息 | 日志脱敏;错误只回错误码 |
| DoS | 大量 op 灌入 | 限流(10 req/s)、单批 500 ops、payload 256KB 上限 |
| Elevation of privilege | 越权读他人快照 | 所有查询强制 `user_id = 当前用户` |

### 3.2 令牌与口令

- 口令:`argon2id`(内存 64MB、迭代 3、并行 1),最短 8 位;失败登录不区分"邮箱不存在/口令错误"。
- Access Token:JWT HS256,30 分钟;密钥从环境变量读取,禁止硬编码。
- Refresh Token:256-bit 随机串,服务端仅存 SHA-256;使用即轮换,旧令牌立即失效;30 天过期。
- 客户端:令牌存平台安全存储(Android EncryptedSharedPreferences / 鸿蒙 preferences 加密 / Windows DPAPI 或本地文件权限限制)。

### 3.3 传输与静态数据

- 强制 HTTPS/WSS(TLS 1.2+);生产禁用明文端口。
- 数据库静态加密由部署层负责(磁盘加密 / 云 RDS 加密),备份同策略。
- 客户端本地库不额外加密(MVP);二期评估 SQLCipher / 端到端加密。

### 3.4 安全测试清单(Sprint 5 执行)

- [ ] 越权访问:用 A 的令牌请求 B 的资源 → 404/403
- [ ] 令牌重放:旧 refresh 再次使用 → 401
- [ ] 注入:payload 中夹带非法字段/超长字符串 → 400 且不落库
- [ ] 限流:并发 100 请求 → 超限返回 `RATE_LIMITED`
- [ ] 日志审计:全量日志 grep 无 token/口令/备注正文
